# HIS Weekly Student Assessment

A mobile-friendly GitHub Pages assessment app for Halley International School.

## Features
- Classes and student lists
- One-tap ✓ / ✗ weekly assessment
- Automatic student rating
- Saved assessments in browser localStorage
- A4 landscape PDF export matching the supplied assessment layout
- School identity: Halley International School – HIS
